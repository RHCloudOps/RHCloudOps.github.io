2. 常用操作快捷键

  • 导航：
    • ↑/↓：逐行滚动。
    • Page Up/Page Down：翻页。
    • Home/End：跳转至开头/结尾。
  • 搜索：
    • /关键字：向前搜索（如 /--help）。
    • n：跳转到下一个匹配项。
    • N：跳转到上一个匹配项。
  • 退出：
    • q：退出手册。

3. 常用命令选项

3.1 搜索相关手册

  • **-k 或 --apropos**：按关键字搜索手册（类似apropos）：

  • **-f 或 --whatis**：显示命令的简短描述（类似whatis）：

3.2其他选项

  • **-a**：显示所有匹配章节的手册（按q后继续下一章节）：

  • **-w**：显示手册页的路径：

4. 手册章节说明

章节 内容
1 用户命令（可执行程序或 shell 命令）
2 系统调用（由内核提供的函数）
3 C 库函数（printf、malloc 等）
4 设备文件（/dev 下的设备）
5 配置文件（系统配置文件格式）
6 游戏和娱乐
7 杂项（宏包、惯例等）
8 管理命令（仅 root 可执行的命令）
9 内核相关文档

四、man手册常用命令速查表

1. 用户命令（User Commands）

命令 功能描述 常用参数示例
文件操作
ls 列出目录内容 -l（长格式） -a（显示隐藏） -h（人类可读大小）
cd 切换目录 cd ~（家目录） cd -（返回上一目录）
pwd 显示当前工作目录路径 无参数
cp 复制文件/目录 -r（递归复制目录） -i（交互确认） -p（保留属性）
mv 移动/重命名文件 -n（不覆盖） -v（显示过程）
rm 删除文件 -r（递归删除） -f（强制） -i（交互确认）
find 高级文件搜索 -name "*.log" -type f（文件） -mtime +7（7天前修改） -exec rm {} \;
文本处理
grep 文本搜索 -i（忽略大小写） -r（递归搜索） -v（反向匹配） -E（扩展正则）
awk 文本分析处理 awk '{print $1}'（打印首列） -F:（指定分隔符）
sed 流编辑器 sed 's/old/new/g'（全局替换） -i（直接修改文件）
vim 高级文本编辑器 :wq（保存退出） :set nu（显示行号） :%s/old/new/g（全局替换）
系统监控
ps 进程查看 aux（BSD格式） -ef（标准格式） --sort=-%cpu（CPU排序）
top 动态进程监控 -b（批处理模式） -n 1（运行1次） -p PID（监控指定进程）
free 内存使用情况 -m（MB显示） -h（人类可读） -s 5（每5秒刷新）
df 磁盘空间统计 -h（人类可读） -T（显示文件系统类型） -i（inode使用）
du 文件/目录大小计算 -sh（汇总显示） --max-depth=1（限制层级） -ah（全部文件+人类可读）
网络工具
wget 文件下载 -c（断点续传） -O filename（重命名） --limit-rate=200k（限速）
curl 数据传输 -o file（保存文件） -X POST（指定方法） -d "key=value"（POST数据）
ssh 远程登录 -p 22（指定端口） -i key.pem（密钥登录） -L 8080:localhost:80（端口转发）
scp 安全文件传输 -r（递归复制） -P 22（指定端口） -C（压缩传输）
rsync 高效文件同步 -avz（归档+压缩+verbose） --delete（同步删除） --exclude="*.tmp"（排除）
权限管理
chmod 修改文件权限 755 u+x（用户添加执行） -R（递归操作）
chown 修改文件所有者 user:group file -R（递归操作） --reference=file1 file2（参照权限）
包管理
yum RPM包管理 install httpd remove package update search keyword groupinstall

2. 系统调用（System Calls）

系统调用 功能描述 典型使用场景
文件操作
open 打开/创建文件 O_RDONLY（只读） O_CREAT（创建） O_WRONLY（只写）
read 读取文件内容 配合文件描述符使用
write 写入文件内容 需指定写入位置和大小
close 关闭文件描述符 释放系统资源
stat 获取文件状态 检查文件大小/权限/时间戳
进程控制
fork 创建子进程 Shell命令执行基础
execve 执行新程序 替换当前进程映像
exit 终止进程 返回状态码（0=成功）
wait 等待子进程结束 获取子进程退出状态
kill 发送信号给进程 SIGKILL（强制终止） SIGTERM（优雅终止）
内存管理
brk/sbrk 调整堆内存大小 动态内存分配基础
mmap 内存映射文件 高效大文件读写
munmap 解除内存映射 释放映射区域
网络通信
socket 创建网络套接字 AF_INET（IPv4） SOCK_STREAM（TCP）
bind 绑定IP和端口 服务端必备
listen 监听连接请求 设置最大连接队列
accept 接受客户端连接 返回新套接字描述符
connect 建立远程连接 客户端使用
send/recv 发送/接收网络数据 带控制标志（如MSG_WAITALL）

4. 特殊文件（Special Files）

设备文件 功能描述 典型用法示例
/dev/null 数据黑洞（丢弃所有写入） command > /dev/null 2>&1（屏蔽输出）
/dev/zero 无限零字节源 dd if=/dev/zero of=file bs=1M count=100（生成空文件）
/dev/random 阻塞式随机数生成器 需要高熵源的场景（如密钥生成）
/dev/urandom 非阻塞随机数生成器 一般加密场景
/dev/sda 第一块SATA硬盘 fdisk /dev/sda（分区操作）
/dev/tty 当前终端设备 交互式输入输出
/dev/loop 回环设备 mount -o loop image.iso /mnt（挂载ISO）
/dev/console 系统控制台 内核消息输出

5. 配置文件格式（File Formats）

配置文件 功能描述 关键字段/结构说明
/etc/passwd 用户账户信息 username:x:UID:GID:描述:家目录:登录Shell
/etc/shadow 加密密码存储 username:加密密码:最后修改:最小天数:最大天数:警告期:失效期:保留
/etc/group 用户组信息 groupname:x:GID:成员列表
/etc/fstab 文件系统挂载表 设备/UUID 挂载点 文件系统类型 挂载选项 dump标志 fsck顺序
/etc/hosts 本地主机名解析 IP地址 主机名 别名
/etc/resolv.conf DNS解析配置 nameserver 8.8.8.8 search domain.com
/etc/crontab 系统级定时任务 分钟 小时 日 月 周 用户 命令
/etc/ssh/sshd_config SSH服务端配置 Port 22 PermitRootLogin no PasswordAuthentication yes

8. 系统管理命令（System Administration）

命令 功能描述 常用参数示例
服务管理
systemctl 控制systemd服务 start/stop/restart 服务名 enable/disable（开机启停） status（查看状态）
journalctl 查询systemd日志 -u nginx（按服务筛选） -f（实时跟踪） --since "2023-01-01"（时间筛选）
磁盘管理
fdisk 磁盘分区工具 -l（列出分区表） /dev/sda（操作指定磁盘）
mkfs 创建文件系统 -t ext4 /dev/sda1（格式化分区）
mount 挂载文件系统 -t nfs（指定类型） -o ro（只读挂载）
用户管理
useradd 创建用户 -m（创建家目录） -s /bin/bash（指定Shell） -G wheel（附加组）
passwd 修改密码 passwd username（修改指定用户） -l（锁定账户）
网络管理
firewall-cmd firewalld防火墙管理 --add-port=80/tcp --permanent --reload
tcpdump 网络抓包工具 -i eth0（指定网卡） port 80（过滤端口） -w file.pcap（保存到文件）
软件管理
rpm RPM包操作 -ivh package.rpm（安装） -e package（卸载） -qa（查询所有）
